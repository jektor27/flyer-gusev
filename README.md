# Флаер Гусев — Каталог магазинов и товаров

Рекламный каталог магазинов города Гусев, Калининградская область.

## Возможности

- 📋 Каталог магазинов по категориям
- 🔍 Поиск товаров и магазинов
- 📱 Адаптивный дизайн (мобильные устройства)
- 🎨 Современный интерфейс
- 📊 Статистика магазинов и товаров

## Категории

- 🪑 Мебель
- 🛒 Продукты
- 🧱 Стройматериалы
- 👗 Одежда
- 💻 Техника
- 🏠 Бытовая химия
- 💊 Аптеки
- 🚗 Авто

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/username/flyer-gusev.git
```

2. Откройте `index.html` в браузере

## Структура проекта

```
flyer-gusev/
├── index.html          # Главная страница
├── category.html       # Страница категории
├── css/
│   └── style.css       # Стили
├── js/
│   └── main.js         # JavaScript
└── img/                # Изображения
```
